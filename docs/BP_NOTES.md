# 正念饭崽 · 商业计划书要点（来自《正念饭崽.pptx》38 页）

> 提取自项目商业介绍书，用于产品定位与功能核对。

## 一、定位

**一个可以针对慢病饮食管理的伴侣机器人 —— 正念饭崽**
「食愈未来」——AI 驱动的正念饮食慢病干预助手。

聚焦**老年慢性病（高血压、糖尿病等）患者**的饮食管理核心痛点，依托 AI 图像识别、
营养大数据、个性化推荐算法及语音交互技术。

## 二、四大核心公益服务

1. **食材识别与慢病适配分析**
2. **个性化膳食方案生成**
3. **三阶正念进食引导**（餐前 / 餐中 / 餐后）
4. **营养数据追踪与预警**

目标：帮老人建立「知食、择食、正念食」的健康饮食习惯。

## 三、痛点（需求依据）

- 我国超过 **75%** 老年人患至少一种慢性病，不合理饮食是主因之一
- 老人普遍缺乏个性化饮食指导，存在「不敢吃 / 乱吃 / 吃错」
- 独居空巢老人进食不规律、**进食过快**、**情绪性进食**，缺乏正念饮食意识
- 现有饮食管理 APP 操作复杂、多为记录工具，缺乏针对性、互动性与陪伴感

**理论支撑**：自我决定理论（SDT）+ 正念饮食理论；情绪性进食与进食过快会预测体重增加，
是肥胖、胃肠道疾病与心理压力的重要诱因。

## 四、三个关键交互范式（已内化为 AI 提示词场景）

| 场景 | 用户 | 期望回复风格 |
|---|---|---|
| 庆祝 | 「今天升职了！必须吃顿好的庆祝一下！」 | 先共情祝贺，再引导「用正念的方式庆祝」：选真正想吃的、坐下来慢慢品尝每口，既享受喜悦也避免后悔 |
| 压力 | 「我快崩溃了！压力太大了！」 | 承认压力 → 引导三次深呼吸 → 建议先不做决定（包括吃东西）→ 邀请说出发生了什么 / 做简短身体扫描 |
| 慢病 | 「我有糖尿病，吃这个正念饮食会不会影响血糖？」 | 说明正念饮食帮助觉察饥饿与饱足，但**不能替代降糖药或胰岛素**；若改变进食模式建议监测血糖并与医生讨论 |

## 五、三阶段研究框架（对应产品数据流）

1. **感知**：计算机视觉实时采集食物种类、进食速度、面部表情、生理信号
2. **分析**：AI 识别不良饮食习惯与潜在健康风险，评估心理状态与进食动机
3. **干预**：通过智能设备与个性化建议及时干预，引导健康饮食习惯

## 六、量化目标（技术验收参考）

- 常见食材识别 ≥ **50 种**，准确率 ≥ **90%**
- 基础进食速度、表情情绪捕捉与纠正准确率 ≥ **80%**
- 累计服务用户 ≥ 50 名，试用满意度 ≥ 80%，多模块服务使用率 ≥ 90%

## 七、道德与安全边界（产品红线）

- 不做诊断、不替代药物；涉及慢病一律提示遵医嘱与监测指标
- 公益导向：面向社区、养老院、居家老人免费试用
- 数据本地化优先（本项目默认全部数据落在设备本地 /data）

## 八、团队与落地

杭州医学院 5 人团队（负责人陈沁岚），医工结合；已对接 2 个社区、3 个养老院。
五阶段六步实施：需求调研 → 机器人研发 → 测试优化（20 名老人试用）→ 落地服务 → 总结推广。
